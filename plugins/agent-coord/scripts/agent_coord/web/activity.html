Recording and coverage

Activity stays in this app’s local history. Visits record foreground interactions, not time spent or keystrokes. Restored foreground views appear as system events only. Agent output and restored background tabs do not count as human visits.

Returns are repeat visits to a thread. “No message” counts completed visits without an accepted message. Missing visit endings remain incomplete. Recording starts here; earlier activity is not reconstructed.
