How to read the prices

  1. A free interface still needs a model and a machine. The host must stay available for work to continue. Remote access alone does not supply compute.
  2. A seat is not a workspace-hour. Fixed subscriptions, dedicated machines, memory-hours and token billing have different cost drivers. Published machine sizes are not performance benchmarks.
  3. Vendor support is architecture-specific. Competitor subscription claims do not establish permission for Agent Coord’s hosted integration. OpenAI directs paid/hosted ChatGPT-plan apps to its partner path. [15]
  4. Features are published claims. “Not established” means the cited sources did not settle the question. It does not mean the feature is absent.

Where Agent Coord could fit

$99 / workspace / month

Draft base offer: one persistent 8 GB Linux VM, application, managed updates and bounded backups. Draft large offer: $179/month for 16 GB. Provider model access remains separate.

Existing product foundation

Codex browser conversations, approvals, queued instructions, checkpoints, thread organization, scope conflict detection and durable messaging. Claude terminal coordination does not yet imply equivalent browser support.

Positioning hypothesis

Reliable decisions and handoffs across ongoing work. Demonstrate more accurate next actions, preserved validation evidence, and better recovery than the free alternatives.

Based on the October 7 product proposal and repository review. Hosted authentication, sizing, willingness to pay and service commitments remain unvalidated.
